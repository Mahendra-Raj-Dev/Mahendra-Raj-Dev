## Featured project

**[Medicare Inpatient Charge vs. Reimbursement Analytics](https://github.com/Mahendra-Raj-Dev/healthcare-rcm-charge-reimbursement-analytics)**

An end-to-end analysis of 145,879 hospital-DRG records from CMS Medicare inpatient data (2024), comparing what hospitals charge with what Medicare pays.

- Cleaned and validated the data in Pandas, modeled it in SQLite, and wrote 11 SQL queries (CTEs, window functions, weighted aggregation).
- Built a Power BI dashboard with DAX measures and state, DRG and rural-urban filters.
- Finding: Nevada's charge-to-payment ratio (10.75) was 1.8x the national ratio (6.09), driven by specific hospitals and persisting on a single DRG.

**Stack:** Python, Pandas, SQLite, SQL, Power BI
